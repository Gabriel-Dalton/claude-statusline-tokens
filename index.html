statusline-tokens
GitHub v0.8.1

Tokens, dollar cost and reset times in your Claude Code status line.

Claude Code shows how much of your limit is used. This adds how many tokens that was, what it would cost at API rates, and when the limit resets. One PowerShell file for Windows, free and open source.

Install

You need Windows 10 or 11, Git, and Claude Code with at least one conversation behind it. PowerShell is already on Windows. It is built and tested on Windows only.

  1. Clone the repository. 
    git clone https://github.com/Gabriel-Dalton/claude-statusline-tokens
  2. Run the setup script.

    It shows the change it wants to make to settings.json and asks before writing. A backup is saved first. Add -DryRun to see the change without making it.

    cd claude-statusline-tokens; .\setup.ps1
  3. Open a new Claude Code window.

    The status line appears on the next prompt. A conversation that was already open keeps its old one.

Prefer to edit settings.json by hand, or something went wrong? The README covers both.

Questions

Is the dollar figure my bill?
No. It is what the same tokens would cost at Anthropic's published API rates. On Pro, Max, Team or Enterprise you pay your flat fee whatever it says. Read it as a measure of how hard you are working the model.
Why is the token count so high?
Most of it is cache reads. Claude Code sends the conversation again on every turn, and those tokens are counted each time. In one measured 5-hour session, 97.7% of the tokens were cache reads.
Does it send my data anywhere?
There is no telemetry and no third party. Everything is read from files Claude Code already keeps on your disk, with one exception: the Fable limit is fetched from Anthropic's own usage endpoint every 15 minutes, using the sign-in Claude Code already has. Set STATUSLINE_SCOPED_LIMITS=0 to turn that off.
Does it work with more than one account or computer?
A session started in its own config folder shows its own account. Totals cover the computer you are on; to include your others, set STATUSLINE_DEVICES_DIR to a shared folder on each. Each computer then writes one file there with its name, a hash of the organization id, and its token and cost totals.
Will it slow my prompt down?
A render takes about a second, a third of which is PowerShell starting. That was measured with 840 MB of transcripts from one week. With several windows open, only one of them rescans at a time.
How are the numbers worked out?
Percentages and reset times come straight from Claude Code. Tokens are added up from your local transcripts, counted once per message and priced by the model each turn used. scripts/verify-tokens.ps1 recomputes them a second way so you can check. The README has the detail.
